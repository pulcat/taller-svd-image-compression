# Taller SVD Compresion de Imagenes

Proyecto de compresión de imágenes utilizando Singular Value Decomposition (SVD).

## Objetivos

- Aplicar SVD a imágenes en escala de grises.
- Reconstruir aproximaciones de bajo rango.
- Analizar compresión, error y energía capturada.

## Tecnologías

- Python
- NumPy
- Matplotlib
- Pillow
